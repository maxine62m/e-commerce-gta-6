# NEON STACK — boutique monoproduit

Prototype statique (HTML/CSS/JS + Three.js), à convertir ensuite en thème Shopify.

Lancer en local : `python3 -m http.server 8000` puis http://localhost:8000

- `index.html` : page produit
- `assets/js/lamp3d.js` : lampe en 3D (textures générées, aucun modèle externe)
- `assets/js/main.js` : panier, compte à rebours (19/11), galerie, FAQ
- Les avis clients sont des EXEMPLES : à remplacer avant la mise en ligne.
